Project Lazarus: Algorithmic Scanner

Project Lazarus is a multi-agent algorithmic trading intelligence system engineered in Python to identify and distribute high-probability intraday options setups in real time. The platform operates through two independent autonomous bots — the Main Bot and the Lotto Bot — each designed for distinct market conditions and risk profiles.

The Main Bot focuses on momentum continuation strategies using multi-timeframe confirmation logic across QQQ, SPY, NVDA, META, AAPL, TSLA, and SPX. The engine continuously processes live 5-minute and 15-minute OHLCV market data streams through Pandas and TA-Lib indicator pipelines, calculating EMA crossovers, VWAP positioning, RSI momentum, volatility regimes, and abnormal volume expansion.

When bullish breakout conditions align, the system dynamically selects high-liquidity ATM 0DTE option contracts, calculates risk-adjusted targets and stop-loss levels, and dispatches fully formatted Discord intelligence alerts in real time.

The Lotto Bot operates as a separate high-risk reversal scanner optimized for far OTM 0DTE contracts. It specializes in detecting failed opening range breakouts, VWAP rejections, RSI divergences, EMA reclaim failures, and exhaustion candle formations using custom reversal-detection logic.

Beyond signal generation, Lazarus includes a complete automated trade management and analytics infrastructure. The framework performs live P&L simulation, end-of-day trade reconciliation, CSV report generation, futures monitoring for NQ and YM contracts, statistical backtesting visualization, and automated Discord reporting.
