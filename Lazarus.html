Project Lazarus: Algorithmic Scanner

Project Lazarus is a custom, Python-based algorithmic market scanner designed to monitor the Nasdaq-100 (QQQ) in real-time. The mission objective was to build a highly responsive intelligence pipeline that identifies high-probability options trading setups using live market data.

To achieve real-time accuracy, the system leverages high-frequency REST polling via the Finnhub API. The incoming data streams are processed using Pandas, where an internal buffer calculates a 14-period Relative Strength Index (RSI) and a 5-period Simple Moving Average (SMA). This mathematical filtering strips out market noise and isolates true momentum breakouts.

When the algorithmic conditions are met, the engine dynamically calculates the relevant Zero Days to Expiration (0DTE) strike prices based on the underlying spot price. The bot then formats this intelligence into a professional JSON payload and dispatches it directly to a secure Discord server via Webhooks.

This project is continuously being improved and developed. More features are to be added!
