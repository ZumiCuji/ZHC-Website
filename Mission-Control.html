Mission Control

Mission Control is a real-time aerospace intelligence dashboard I built as part of my portfolio. It functions as a personal mission operations center for tracking satellites, ISS positioning, asteroid threats, earthquakes, Mars weather, and upcoming rocket launches using live NASA APIs and real orbital telemetry.

The system is designed to feel like a planetary defense command interface, combining aerospace engineering concepts with cinematic UI design and real-time data visualization.

What This Project Does

Mission Control aggregates multiple real-world aerospace and Earth monitoring systems into a single interface. It is designed for both visualization and personal use to stay connected with spaceflight activity.

Orbital Tracking

Visualizes ISS and satellite movement using live orbital positioning and 3D Earth rendering.

Asteroid Monitoring

Tracks near-earth objects using NASA’s NEO API with hazard classification and velocity data.

Launch Intelligence

Displays upcoming rocket launches, mission details, and global spaceflight schedules in real time.

How I Use It

I use Mission Control as a daily aerospace dashboard to keep up with my space interests, learn orbital mechanics concepts, and monitor real-world space activity in a single immersive system.

Daily Check

Check ISS position, satellites, and asteroid activity every morning like a mission briefing.

Launch Tracking

Follow upcoming rocket launches and mission updates without switching between multiple sites.

Learning Tool

Helps reinforce aerospace engineering concepts through real-time visualization and data.
